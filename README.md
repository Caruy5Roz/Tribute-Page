# 🕊️ Tribute Page

This is a simple frontend project — a tribute page created as part of my web development learning journey.

🔗 [Live Demo](https://caruy5roz.github.io/Tribute-Page/)

---

## 📌 About the Project

Tribute Page is a single-page website dedicated to a notable individual. It is built with **pure HTML5 and CSS3**, without any JavaScript or frameworks. The focus is on structure, semantics, and visual layout using Flexbox.

---

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox)
- Git + GitHub Pages
